# 智能房贷计算器 🏠

一个功能完整、界面美观的房贷计算器，支持等额本息和等额本金两种还款方式。

## 功能特点

### 📊 核心计算功能
- **等额本息**：每月还款额固定，适合收入稳定的上班族
- **等额本金**：每月还款本金固定，总利息较少，适合前期还款能力强的借款人
- **实时计算**：输入参数即时更新计算结果
- **精确计算**：基于标准房贷计算公式，结果准确可靠

### 🎨 用户界面
- **现代化设计**：渐变背景、卡片布局、圆角设计
- **响应式布局**：完美适配手机、平板和桌面设备
- **交互友好**：滑块+输入框双重控制，操作便捷
- **实时反馈**：输入变化即时反映在计算结果中

### 🔧 高级功能
- **本地存储**：自动保存您的输入，下次访问无需重新输入
- **分享功能**：一键分享计算器链接给朋友
- **键盘快捷键**：
  - `Ctrl + Enter`：重新计算
  - `Esc`：重置为默认值
- **理财建议**：提供实用的房贷管理建议
- **对比分析**：显示第一年与最后一年利息对比

## 使用说明

### 输入参数
1. **贷款总额**：10万 - 1000万元（使用滑块或直接输入）
2. **贷款年限**：1 - 30年
3. **年利率**：1% - 10%
4. **还款方式**：等额本息 / 等额本金

### 计算结果
- **月供金额**：每月需要还款的金额
- **总利息**：贷款期间支付的总利息
- **还款总额**：本金 + 总利息
- **利息对比**：第一年 vs 最后一年利息支出

## 技术实现

### 计算公式
#### 等额本息
```
月利率 = 年利率 / 12 / 100
还款月数 = 贷款年限 × 12
月供 = 本金 × 月利率 × (1 + 月利率)^还款月数 ÷ [(1 + 月利率)^还款月数 - 1]
总利息 = 月供 × 还款月数 - 本金
```

#### 等额本金
```
月利率 = 年利率 / 12 / 100
每月本金 = 本金 ÷ 还款月数
首月月供 = 每月本金 + 本金 × 月利率
每月递减额 = 每月本金 × 月利率
总利息 = (还款月数 + 1) × 本金 × 月利率 ÷ 2
```

4. 保存后等待部署完成
